# Ethan Norland — Portfolio

> Creative Technologist, Visual Brand Designer & 3D Web Craftsman

This repository hosts the personal portfolio website of **Ethan Norland**, published live on GitHub Pages at:
**[https://ethannorland.github.io/](https://ethannorland.github.io/)**

## Featured Works
- **[Bracelet Designer](https://ethannorland.github.io/braceletdesigner/):** Interactive 3D WebGL atelier for custom jewelry design with tactile beads, direct raycasting, and millimeter fit testing.
- **Liquid Death Halloween Poster:** Large-format brand campaign poster celebrating subversive humor and bold typography.
- **Best and Worst of Disney World:** Editorial 8-page print publication and zine design.
- **Stan Lee Typographic Tribute Portrait:** Digital typography illustration created from Stan Lee's quotes and characters.
- **Footwear Study (Shoe Drawing):** Observational graphite illustration examining texture, material creases, and form.

## Technology
- Pure client-side HTML5, CSS3, and JavaScript
- Hosted on GitHub Pages at the root of `ethannorland.github.io`
